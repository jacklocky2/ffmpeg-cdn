ffmpeg-cdn · 自托管 ffmpeg.wasm ESM

api/index.js 是唯一入口，同时导出 @ffmpeg/ffmpeg 的 FFmpeg 和 @ffmpeg/util 的工具函数。

import { FFmpeg, fetchFile } from "https://jacklocky2.github.io/ffmpeg-cdn/api/index.js";

const ffmpeg = new FFmpeg();
ffmpeg.on("log", ({ message }) => console.log(message));

// core 已默认指向本仓库自托管的 ESM 构建，load() 无需传参
await ffmpeg.load();

await ffmpeg.writeFile("input.mp4", await fetchFile(file));
await ffmpeg.exec(["-i", "input.mp4", "-c:v", "libx264", "-crf", "28", "-c:a", "copy", "output.mp4"]);
const data = await ffmpeg.readFile("output.mp4");

也可以显式指定（例如换多线程 core）：
await ffmpeg.load({ coreURL: ".../ffmpeg-core.js", wasmURL: ".../ffmpeg-core.wasm" })
注意必须是 ESM 构建 —— worker 以 type: "module" 启动，importScripts() 不可用，core 通过动态 import() 取其 default 导出。
